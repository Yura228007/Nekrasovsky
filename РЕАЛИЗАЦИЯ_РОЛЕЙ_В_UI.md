## 📋 Использование

### Создание пользователя с ролью:
1. Нажать кнопку "Добавить" на странице пользователей
2. Заполнить данные пользователя (логин, пароль, имя, фамилия, email, телефон)
3. Выбрать роль из списка (или "Без роли")
4. Сохранить пользователя

### Редактирование роли пользователя:
1. Выбрать пользователя из списка
2. Нажать "Редактировать"
3. Изменить данные пользователя
4. Выбрать новую роль (или "Без роли" для удаления роли)
5. Сохранить изменения

### Просмотр роли пользователя:
- Роль отображается в списке пользователей под логином
- Роль также отображается в диалоге "Просмотр" пользователя

## 🔧 Технические детали

### API Endpoints:
- `GET /api/roles` - получение всех ролей
- `GET /api/roles/{id}` - получение роли по ID

### Модель Role:
```csharp
public class Role
{
    public int Id { get; set; }
    public string Name { get; set; }
    public string Code { get; set; }
    public string? Description { get; set; }
    public int Rank { get; set; }
}
```

### Связь User-Role:
- Пользователь может иметь одну роль (`RoleId`)
- Роль может быть не назначена (`RoleId = null`)
- При обновлении пользователя роль также обновляется
