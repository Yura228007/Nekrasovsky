## Критические исправления для DateTime

**Проблема:** Пустые строки для DateTime полей через Swagger вызывают краш процесса.

**Решение применено в:**
- ✅ AlarmEventsController (date-range, CreatedAt)
- ✅ WorkReportsController (date, date-range, StartWork, FinishWork, StartTime, FinishTime)
- ✅ ShiftTransfersController (date, TransferDate)
- ✅ RequestLogsController (date-range, beforeDate, startDate, endDate)

**Паттерн валидации:**
1. Изменены параметры DateTime на string? в query параметрах
2. Добавлена валидация: проверка на null/пустую строку
3. Парсинг через DateTime.TryParse с валидацией
4. Возврат BadRequest с понятным сообщением при ошибке парсинга
5. Для body параметров - проверка на default(DateTime)
