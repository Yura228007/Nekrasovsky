# Развёртывание сервера Nekrasovsky при статическом белом IP — пошаговая инструкция

Сервер слушает **HTTP на порту 9000** и **HTTPS на порту 5001**.  
Ваш белый IP: **213.108.172.138** (провайдер РЕАЛ, Астрахань, Энергетический 8-й проезд, 7/1).

---

## Шаг 1. Ввести параметры провайдера в роутере

1. Откройте браузер на любом ПК в вашей сети.
2. В адресной строке введите адрес роутера и нажмите Enter:
   - чаще всего: **192.168.0.1** или **192.168.1.1**
   - если не подходит — смотрите на наклейку на роутере или в инструкции к нему.
3. Введите логин и пароль администратора роутера (часто указаны на наклейке; если меняли — используйте свои).
4. В меню роутера найдите раздел подключения к интернету. Если вы уже в разделе **«Сеть»** и видите список подразделов:
   - выберите **«Настройка WAN»** (или **«WAN»**, **«Настройки WAN»**). Именно там задаётся подключение к провайдеру и вводятся IP, маска, шлюз и DNS.
   - Не выбирайте: настройка LAN, настройки коммутатора, VLAN, гостевые сети, список адресов, имена хостов, IPv6, маршруты, диагностика — это не то.
5. Откройте **«Настройка WAN»** и выберите тип настройки:
   - вместо «Автоматически (DHCP)» выберите **«Вручную»**, **«Статический IP»** или **«Static IP»**.
6. В появившихся полях введите (по одному значению в каждое поле):

   | В поле роутера пишите | Значение |
   |-----------------------|----------|
   | IP-адрес / IP         | **213.108.172.138** |
   | Маска подсети / Subnet mask | **255.255.255.0** |
   | Шлюз / Gateway        | **213.108.172.1** |
   | Основной DNS / DNS 1  | **195.82.134.6** |
   | Доп. DNS / DNS 2      | **62.33.183.254** |

7. Нажмите **«Сохранить»** / **«Применить»** (Apply / Save).
8. Если роутер предложит перезагрузку — выполните её и дождитесь включения.

**Итог:** роутер получил статический белый IP от провайдера. Для приложения и проверки из интернета используйте адрес **213.108.172.138**.

## Шаг 2. Узнать внутренний IP ПК, на котором будет сервер

1. Включите тот ПК, где будет стоять сервер Nekrasovsky, подключите его к той же сети (кабель или Wi‑Fi).
2. Откройте командную строку:
   - **Windows:** нажмите Win + R, введите **cmd**, нажмите Enter.
   - **Linux:** откройте терминал.
3. Введите команду и нажмите Enter:
   - **Windows:** `ipconfig`
   - **Linux:** `hostname -I` или `ip addr`
4. Найдите адрес вида **192.168.x.x** (реже 10.x.x.x):
   - в Windows смотрите блок «Адаптер беспроводной локальной сети» или «Ethernet» — строка **IPv4-адрес**;
   - в Linux — первое число в выводе.
5. Запишите этот адрес (например, **192.168.1.100**) — он понадобится для проброса портов.

**Опционально (чтобы IP не менялся):** в веб-интерфейсе роутера найдите раздел **DHCP** → **Резервирование адресов** / **Привязка MAC–IP**. Узнайте MAC-адрес ПК (в Windows: `ipconfig /all`, строка «Физический адрес»). В роутере привяжите этот MAC к выбранному IP (например, 192.168.1.100) и сохраните.

## Шаг 3. Установить .NET 8 на ПК с сервером (Windows)

1. Откройте в браузере: https://dotnet.microsoft.com/download/dotnet/8.0
2. В списке найдите **ASP.NET Core Runtime 8.0** (если будете только запускать готовое приложение) или **.NET SDK 8.0** (если будете собирать проект на этом ПК).
3. Нажмите **Windows** и скачайте установщик (x64).
4. Запустите скачанный файл (.exe).
5. В мастере установки нажимайте **Next** → дождитесь окончания → **Close**.
6. Закройте и снова откройте командную строку (или PowerShell).
7. Введите: `dotnet --version` и нажмите Enter.
   - Должно появиться число вида **8.0.xxx**. Если команда не найдена — перезагрузите ПК и повторите.

## Шаг 4. Установить PostgreSQL на ПК с сервером (Windows)

1. Откройте в браузере: https://www.postgresql.org/download/windows/
2. Нажмите **«Download the installer»** (официальный установщик).
3. Выберите последнюю версию **16** (или 15, 14) и скачайте установщик для Windows x86-64.
4. Запустите скачанный .exe.
5. На экране выбора компонентов оставьте всё по умолчанию, нажмите **Next**.
6. Укажите папку установки (можно не менять), нажмите **Next**.
7. В поле **Data Directory** можно оставить по умолчанию, нажмите **Next**.
8. В поле **Password** введите пароль пользователя **postgres** (придумайте и запишите — он понадобится для `appsettings.json`). Повторите пароль во втором поле. Нажмите **Next**.
9. Порт оставьте **5432**, нажмите **Next**.
10. Язык оставьте по умолчанию, нажмите **Next** → **Next** → **Install** → дождитесь окончания → **Finish**.
11. Создайте базу для приложения:
    - Откройте **pgAdmin** из меню «Пуск» (или «SQL Shell (psql)»).
    - В pgAdmin: слева раскройте **Servers** → **PostgreSQL**; при первом входе введите пароль пользователя postgres, который задали в п. 8.
    - Правой кнопкой по **Databases** → **Create** → **Database**.
    - В поле **Database** введите: **Nekrasovsky**. Остальное не меняйте. Нажмите **Save**.

Дополнительно настраивать PostgreSQL под белый IP не нужно — база используется только на этом ПК.

## Шаг 5. Опубликовать приложение (сборка)

1. На ПК, где лежит исходный код проекта (может быть тот же серверный ПК или другой), откройте командную строку (или PowerShell).
2. Перейдите в папку проекта сервера. Введите (подставьте свой путь, если другой):
   ```text
   cd d:\Projects\Nekrasovsky\server\server
   ```
   Нажмите Enter.
3. Выполните команду публикации:
   ```text
   dotnet publish -c Release -o C:\Publish\NekrasovskyServer
   ```
   Нажмите Enter и дождитесь окончания (в конце должно быть «Build succeeded»).
4. Откройте проводник и проверьте, что появилась папка **C:\Publish\NekrasovskyServer** с файлами (в том числе **server.dll**, **appsettings.json**).
5. Если сборка была на другом ПК — скопируйте всю папку **NekrasovskyServer** на тот ПК, где будет работать сервер (например, на рабочий стол или в **C:\Publish\**).

## Шаг 6. Настроить строку подключения к базе

1. Откройте проводник и перейдите в папку публикации: **C:\Publish\NekrasovskyServer**.
2. Найдите файл **appsettings.json** и откройте его блокнотом (правой кнопкой → «Открыть с помощью» → «Блокнот»).
3. Найдите строку с **DefaultConnection** (в блоке `"ConnectionStrings"`). Она может выглядеть так:
   ```text
   "DefaultConnection": "Host=localhost;Port=5432;Database=Nekrasovsky;Username=postgres;Password=admin"
   ```
4. Замените **Password=admin** (или текущее значение) на ваш реальный пароль пользователя postgres, который вы задали при установке PostgreSQL. Например:
   ```text
   "DefaultConnection": "Host=localhost;Port=5432;Database=Nekrasovsky;Username=postgres;Password=ВашПароль"
   ```
5. Сохраните файл (Файл → Сохранить) и закройте блокнот.

## Шаг 7. Первый запуск сервера и проверка

1. Откройте командную строку (Win + R → **cmd** → Enter).
2. Введите по очереди и нажимайте Enter:
   ```text
   cd C:\Publish\NekrasovskyServer
   dotnet server.dll
   ```
3. В окне не должно быть красных ошибок. Должна появиться строка о прослушивании портов (9000, 5001). Оставьте это окно открытым.
4. Откройте браузер на этом же ПК.
5. В адресной строке введите: **http://localhost:9000/swagger** и нажмите Enter.
   - Должна открыться страница Swagger (список API). Значит, сервер и база работают.
6. Вернитесь в окно с запущенным сервером и нажмите **Ctrl+C**, чтобы остановить его. Дальше настроим автозапуск.

## Шаг 8. Настроить автозапуск сервера (служба Windows)

1. Скачайте NSSM: откройте https://nssm.cc/download и скачайте архив (например, nssm-2.24.zip).
2. Распакуйте архив. Зайдите в папку **win64** (для 64-битной Windows).
3. Скопируйте файл **nssm.exe** в папку **C:\Publish\NekrasovskyServer** (или оставьте где есть и запомните путь).
4. Откройте командную строку **от имени администратора** (правой кнопкой по «Командная строка» → «Запуск от имени администратора»).
5. Перейдите в папку с nssm.exe. Например:
   ```text
   cd C:\Publish\NekrasovskyServer
   ```
6. Выполните команду (одной строкой):
   ```text
   nssm install NekrasovskyServer "C:\Program Files\dotnet\dotnet.exe" "server.dll"
   ```
   Если dotnet установлен в другую папку — укажите путь к **dotnet.exe** (можно найти через «Поиск» в Пуске).
7. Откроется окно NSSM. На вкладке **Application**:
   - в поле **Startup directory** введите: **C:\Publish\NekrasovskyServer**
   - нажмите **Install service**.
8. Откройте службы Windows: нажмите Win + R, введите **services.msc**, нажмите Enter.
9. В списке найдите **NekrasovskyServer**, щёлкните правой кнопкой → **Запустить**. Убедитесь, что статус «Выполняется».
10. Щёлкните правой кнопкой по **NekrasovskyServer** → **Свойства** → в «Тип запуска» выберите **Автоматически** → **ОК**.

Сервер будет запускаться при каждой загрузке ПК.

## Шаг 9. Открыть порты 9000 и 5001 в брандмауэре Windows

1. Нажмите Win + R, введите **wf.msc**, нажмите Enter (откроется «Брандмауэр Защитника Windows в режиме повышенной безопасности»).
2. Слева выберите **Правила для входящих подключений**.
3. Справа нажмите **Создать правило…**.
4. Выберите **Для порта** → **Далее**.
5. Выберите **Протокол TCP**, в поле «Определённые локальные порты» введите: **9000, 5001** → **Далее**.
6. Выберите **Разрешить подключение** → **Далее**.
7. Оставьте отмеченными все профили (домен, частное, общее) → **Далее**.
8. Имя правила: **Nekrasovsky Server** → **Готово**.

Повторите создание правила для **исходящих** подключений (те же порты), если в вашей политике по умолчанию исходящие блокируются (обычно не требуется).

## Шаг 10. Настроить проброс портов на роутере

**Что вводить (кратко):** в роутере вы настраиваете два правила. Адрес **213.108.172.138** вводить не нужно — это ваш белый IP, он уже у роутера. В полях роутера указываете только **внутренний IP вашего ПК** (который вы записали в шаге 2, например 192.168.1.100) и порты **9000** и **5001**.

1. Откройте браузер и зайдите в веб-интерфейс роутера (как в шаге 1 — 192.168.0.1 или 192.168.1.1).
2. Войдите под учётной записью администратора.
3. Найдите раздел настройки проброса портов. Он может называться:
   - **Виртуальные серверы** / **Port Forwarding** / **Проброс портов** / **NAT** / **Переадресация**.
   - Часто находится в разделах «Сеть», «Интернет», «Дополнительно».
4. Нажмите **Добавить** / **Add** / **Создать правило**.
5. Заполните **первое** правило (для HTTP API и Swagger):

   | Поле в роутере              | Что ввести |
   |-----------------------------|------------|
   | Внешний порт / WAN port     | **9000** |
   | Внутренний IP / LAN IP      | **IP вашего ПК из шага 2** (например 192.168.1.100) |
   | Внутренний порт / LAN port  | **9000** |
   | Протокол                    | **TCP** |

   Сохраните правило.
6. Добавьте **второе** правило (для HTTPS, если будете использовать):

   | Поле в роутере              | Что ввести |
   |-----------------------------|------------|
   | Внешний порт                | **5001** |
   | Внутренний IP               | **тот же**, что в п. 5 (ваш ПК) |
   | Внутренний порт             | **5001** |
   | Протокол                    | **TCP** |

   Сохраните.
7. Нажмите **Сохранить** / **Применить** в интерфейсе роутера. При необходимости перезагрузите роутер.

После этого запросы из интернета на **213.108.172.138:9000** и **213.108.172.138:5001** будут попадать на ваш ПК.

## Шаг 11. Указать адрес сервера в приложении (телефон/ПК)

1. Откройте проект приложения (NekrasovskyAPP) в среде разработки или найдите место, где задаётся адрес сервера (например, `ApiService.cs`, метод `GetBaseUrl()`, или настройки/конфиг приложения).
2. Укажите базовый URL сервера:
   - по HTTP: **http://213.108.172.138:9000/**
   - по HTTPS (если настроен SSL): **https://213.108.172.138:5001/**
3. Сохраните изменения, пересоберите приложение и установите его на телефон или ПК.

## Шаг 12. Проверить доступ из интернета

1. **С ПК-сервера:** откройте браузер, введите **http://localhost:9000/swagger** — страница должна открываться.
2. **С телефона по мобильному интернету** (отключите Wi‑Fi на телефоне, чтобы быть в другой сети): откройте браузер и введите **http://213.108.172.138:9000/swagger**. Должна открыться та же страница Swagger. Если открывается — проброс портов и файрвол настроены верно.
3. Запустите приложение на телефоне, выполните вход — если авторизация проходит, подключение к API по белому IP работает.
