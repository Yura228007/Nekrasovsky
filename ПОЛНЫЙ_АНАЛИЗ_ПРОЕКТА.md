## 🎯 ОБЩЕЕ ОПИСАНИЕ ПРОЕКТА

**Nekrasovsky** - комплексная система управления складом, состоящая из трех основных компонентов:

1. **Backend API Server** (ASP.NET Core)
2. **Android приложение** (Kotlin + Jetpack Compose)
3. **MAUI приложение** (.NET MAUI для Windows и Android)

Проект предназначен для автоматизации складских процессов, управления номенклатурой, отслеживания перемещений материалов и продуктов, а также ведения отчетности о работе сотрудников.

## 🏗️ АРХИТЕКТУРА ПРОЕКТА

### 1. Backend Server (ASP.NET Core)

#### Технологический стек:
- **.NET 8.0** - платформа разработки
- **ASP.NET Core Web API** - RESTful API
- **Entity Framework Core 8.0.10** - ORM
- **PostgreSQL** - база данных
- **SignalR** - real-time уведомления
- **BCrypt.Net-Next 4.0.3** - хэширование паролей
- **Swagger** - документация API

#### Архитектурные паттерны:
- **Repository Pattern** - через сервисы
- **Dependency Injection** - встроенный DI контейнер .NET
- **Middleware** - для аудита запросов
- **Attribute-based Authorization** - через `RequirePermissionAttribute`

#### Структура проекта:
```
server/server/
├── Controllers/        # 17 API контроллеров
├── Services/          # 18 сервисов (бизнес-логика)
├── Models/            # 17 моделей данных
├── Data/              # AppDbContext и миграции
├── Middleware/        # AuditMiddleware для логирования
├── Hubs/              # SignalR Hub для уведомлений
├── Attributes/        # RequirePermissionAttribute
└── Extensions/        # ServiceCollectionExtensions
```

#### Основные компоненты:

**Модели данных (17):**
1. User - пользователи
2. Role - роли
3. Permission - права доступа
4. RolePermission - связь ролей и прав
5. UserPermissions - прямые права пользователей
6. Warehouse - склады
7. Material - материалы
8. Product - продукты
9. Recipe - рецепты
10. AccessibleMovement - разрешенные перемещения
11. PartRequest - запросы на детали
12. AlarmEvent - события тревоги
13. ShiftTransfer - сменные передачи
14. FillingWarehouse - заполнение складов
15. WorkReport - отчеты о работе
16. RequestLog - логи запросов
17. UploadedFile - загруженные файлы

**Контроллеры (17):**
- UsersController

- UserPermissionsController
- WarehousesController
- MaterialsController

- AccessibleMovementsController

**Сервисы (18):**

#### Особенности реализации:

1. **Система ролей и прав:**
   - 11 ролей из ТЗ (Владелец, Администратор, Старший экструзионщик и т.д.)
   - 13 прав из ТЗ (AddUsersAllRanks, Reception, AssignBarcode и т.д.)
   - Двухуровневая система: права через роли + прямые права пользователей
   - Атрибут `[RequirePermission]` для проверки доступа

2. **Безопасность:**
   - BCrypt хэширование паролей
   - HTTPS поддержка с кастомными сертификатами
   - Защита от SQL-инъекций через EF Core
   - Аудит всех запросов через `AuditMiddleware`

3. **Real-time уведомления:**
   - SignalR Hub для уведомлений
   - Уведомления при создании AlarmEvent
   - Уведомления при 3 отказах в PartRequest

4. **Автоматические миграции:**
   - Применение миграций при запуске приложения
   - Обработка ошибок при миграциях

5. **Резервное копирование:**
   - Фоновая служба для автоматического бэкапа
   - Настраиваемый интервал (по умолчанию 24 часа)
