# Исправление проблемы входа в приложение

## Проблема
Не удается войти в приложение, хотя пользователь был добавлен вручную в базу данных.

## Причина
Если пользователь был добавлен напрямую в базу данных (через SQL), пароль может быть сохранен в незашифрованном виде. Сервер пытается расшифровать пароль, и если это не удается, возвращает пустую строку, что приводит к ошибке входа.

## Решение

### Вариант 1: Проверка через API (рекомендуется)

1. **Запустите сервер:**
   ```bash
   cd server/server
   dotnet run
   ```

2. **Проверьте состояние пользователей:**
   Откройте в браузере:
   ```
   http://localhost:5000/api/database/check
   ```
   или через curl:
   ```bash
   curl http://localhost:5000/api/database/check
   ```

   Вы увидите список пользователей и информацию о том, зашифрованы ли их пароли.

3. **Зашифруйте пароль пользователя:**
   Если пароль не зашифрован, отправьте POST запрос:
   ```bash
   curl -X POST http://localhost:5000/api/database/encrypt-user-password \
     -H "Content-Type: application/json" \
     -d '{
       "userId": 1,
       "password": "ваш_пароль"
     }'
   ```
   
   Замените:
   - `userId` на ID вашего пользователя
   - `"ваш_пароль"` на пароль, который вы хотите установить

### Вариант 2: Создание пользователя через API

Вместо добавления пользователя вручную в БД, создайте его через API:

```bash
curl -X POST http://localhost:5000/api/users \
  -H "Content-Type: application/json" \
  -d '{
    "login": "ваш_логин",
    "encryptedPassword": "ваш_пароль",
    "name": "Имя",
    "surname": "Фамилия",
    "email": "email@example.com",
    "phone": "+1234567890"
  }'
```

API автоматически зашифрует пароль перед сохранением.

### Вариант 3: Проверка подключения к БД

Убедитесь, что строка подключения в `appsettings.json` правильная:

```json
{
  "ConnectionStrings": {
    "DefaultConnection": "Host=localhost;Port=5432;Database=Nekrasovsky;Username=postgres;Password=admin"
  }
}
```

Проверьте:
- ✅ PostgreSQL запущен
- ✅ База данных `Nekrasovsky` существует
- ✅ Пользователь `postgres` имеет доступ
- ✅ Пароль правильный

## Что было исправлено

1. **Улучшен `PasswordService.Decrypt()`:**
   - Теперь проверяет, является ли пароль валидным Base64
   - Если пароль не зашифрован, возвращает его как есть (для обратной совместимости)
   - Логирует предупреждения о незашифрованных паролях

2. **Добавлен `DatabaseController`:**
   - `GET /api/database/check` - проверка подключения и состояния пользователей
   - `POST /api/database/encrypt-user-password` - зашифровка пароля пользователя

## Проверка после исправления

1. Запустите сервер
2. Проверьте состояние БД: `http://localhost:5000/api/database/check`
3. Если пароль не зашифрован, зашифруйте его через API
4. Попробуйте войти в приложение

## Дополнительная информация

- Swagger UI: `http://localhost:5000/swagger` - для тестирования API
- Все пароли должны быть зашифрованы перед сохранением в БД
- При создании пользователя через API пароль шифруется автоматически
