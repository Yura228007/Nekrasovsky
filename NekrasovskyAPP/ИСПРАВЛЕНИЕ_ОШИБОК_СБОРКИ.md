# Исправление ошибок сборки

## ✅ Исправлено

### 1. Ошибка XAML - CornerRadius в Border
**Проблема:** `CornerRadius="6"` в Border вызывает ошибку XamlC XFC0009

**Решение:** Заменено на использование `StrokeShape` с `RoundRectangle`:
```xml
<Border BackgroundColor="...">
    <Border.StrokeShape>
        <RoundRectangle CornerRadius="6"/>
    </Border.StrokeShape>
    <!-- содержимое -->
</Border>
```

### 2. Предупреждения о null reference
**Исправлено:**
- Добавлена проверка на null в `BarcodeScannerPage.xaml.cs` при работе с reflection
- Добавлена проверка на null в `SettingsPage.xaml.cs` при работе с response
- Убрана неиспользуемая переменная `ex` в `AuthService.cs`

### 3. Обновление API для BarcodeResult
**Изменено:**
- Приоритет свойства `Value` вместо `Text` для получения значения штрих-кода
- Приоритет свойства `Symbology` для получения типа штрих-кода

## ⚠️ Проблемы с Android типами

### Ошибки компиляции для Android
При сборке проекта для Android возникают ошибки:
```
error CS0246: Не удалось найти тип или имя пространства имен "Android"
error CS0246: Не удалось найти тип или имя пространства имен "MauiAppCompatActivity"
error CS0246: Не удалось найти тип или имя пространства имен "JniHandleOwnership"
```

### Возможные причины
1. **Не установлен MAUI workload для Android**
   - Выполните: `dotnet workload install maui-android`
   - Или через Visual Studio Installer

2. **Не восстановлены пакеты**
   - Выполните: `dotnet restore`
   - Очистите папки `bin` и `obj`, затем пересоберите

3. **Проблемы с конфигурацией проекта**
   - Убедитесь, что `<UseMaui>true</UseMaui>` в .csproj
   - Проверьте, что указаны правильные `TargetFrameworks`

### Решение
1. Проверьте установку MAUI workload:
   ```bash
   dotnet workload list
   ```
   
2. Если отсутствует, установите:
   ```bash
   dotnet workload install maui-android
   ```

3. Очистите и пересоберите проект:
   ```bash
   dotnet clean
   dotnet restore
   dotnet build
   ```

## 📝 Примечания

- Предупреждения о null reference (CS8602) - это warnings, не errors. Проект должен собираться с предупреждениями.
- Ошибки Android типов исчезнут после правильной установки MAUI workload и восстановления пакетов.
- Windows сборка должна работать без ошибок (кроме предупреждений).
