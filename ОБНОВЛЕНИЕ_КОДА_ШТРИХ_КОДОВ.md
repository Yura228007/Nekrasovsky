## 📝 Использование

### Открытие сканера из кода:

```csharp
var scannerPage = new BarcodeScannerPage();
scannerPage.BarcodeScanned += OnBarcodeScanned;
await Navigation.PushModalAsync(scannerPage);
```

## ⚠️ Важные замечания

1. **Windows поддержка**: Сканирование с камеры на Windows может не работать (ограничение библиотеки). На Windows можно использовать генерацию штрих-кодов или альтернативные решения.

2. **Разрешения**: Убедитесь, что разрешения для камеры добавлены:
   - Android: `Platforms/Android/AndroidManifest.xml` - `<uses-permission android:name="android.permission.CAMERA" />`
   - iOS: `Platforms/iOS/Info.plist` - `NSCameraUsageDescription`

3. **Lifecycle**: Камера автоматически включается при появлении страницы и выключается при скрытии.
