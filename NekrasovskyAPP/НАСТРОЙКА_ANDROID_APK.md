# Настройка Android APK для реального устройства

## Проблема
Приложение застревает на заставке и не подключается к серверу при установке APK на реальное Android устройство.

## Причина
По умолчанию приложение настроено для работы с эмулятором (`http://10.0.2.2:5000/`), но для реального устройства нужно использовать IP адрес вашего компьютера в локальной сети.

## Решение

### Шаг 1: Узнайте IP адрес вашего компьютера

#### На macOS/Linux:
```bash
ifconfig | grep "inet " | grep -v 127.0.0.1
```

Или более просто:
```bash
ifconfig en0 | grep "inet "
```

Вы увидите что-то вроде: `inet 192.168.1.100 netmask 0xffffff00`

#### На Windows:
```cmd
ipconfig
```

Найдите `IPv4 Address` под вашим сетевым адаптером (обычно это Wi-Fi адаптер), например: `192.168.1.100`

### Шаг 2: Обновите URL в ApiService.cs

Откройте файл: `NekrasovskyAPP/NekrasovskyAPP/Services/ApiService.cs`

Найдите метод `GetBaseUrl()` и обновите для Android:

```csharp
private static string GetBaseUrl()
{
#if ANDROID
    // Замените XXX на IP адрес вашего компьютера
    string androidUrl = "http://192.168.1.XXX:5000/"; // Ваш IP
    
    return androidUrl;
#else
    return "http://localhost:5000/";
#endif
}
```

**Пример:**
Если IP вашего компьютера `192.168.1.100`, то:
```csharp
string androidUrl = "http://192.168.1.100:5000/";
```

### Шаг 3: Убедитесь, что сервер запущен и доступен

1. **Запустите сервер:**
   ```bash
   cd server/server
   dotnet run
   ```

2. **Проверьте доступность сервера:**
   Откройте в браузере на компьютере:
   ```
   http://localhost:5000/swagger
   ```

3. **Проверьте доступность с устройства:**
   На Android устройстве откройте браузер и перейдите по адресу:
   ```
   http://ВАШ_IP:5000/swagger
   ```
   Например: `http://192.168.1.100:5000/swagger`
   
   Если страница открывается - значит сервер доступен!

### Шаг 4: Проверьте настройки брандмауэра

Если сервер недоступен с устройства, проверьте настройки брандмауэра:

#### На macOS:
```bash
# Разрешить входящие соединения на порт 5000
sudo pfctl -f /etc/pf.conf
```

Или через настройки системы:
1. Системные настройки → Защита и безопасность → Брандмауэр
2. Убедитесь, что брандмауэр не блокирует входящие соединения

#### На Windows:
1. Откройте "Брандмауэр Защитника Windows"
2. Дополнительные параметры → Правила для входящих подключений
3. Создайте новое правило для порта 5000

### Шаг 5: Пересоберите APK

После изменения URL в `ApiService.cs`:

```bash
cd NekrasovskyAPP/NekrasovskyAPP
dotnet publish -f net8.0-android -c Release
```

APK будет в папке:
```
bin/Release/net8.0-android/publish/com.companyname.nekrasovskyapp-Signed.apk
```

### Шаг 6: Убедитесь, что устройство в той же сети

**Важно:** Компьютер и Android устройство должны быть подключены к одной Wi-Fi сети!

Если компьютер подключен по кабелю, а устройство по Wi-Fi - они могут быть в разных подсетях. Убедитесь, что оба подключены к одной сети.

## Альтернативное решение: Использование ngrok для доступа из интернета

Если нужно протестировать приложение, когда устройство и компьютер в разных сетях:

1. **Установите ngrok:**
   ```bash
   # macOS
   brew install ngrok
   
   # или скачайте с https://ngrok.com/
   ```

2. **Запустите туннель:**
   ```bash
   ngrok http 5000
   ```

3. **Используйте URL от ngrok** (например: `https://abc123.ngrok.io`) в `ApiService.cs`

**⚠️ Внимание:** Это только для тестирования! Не используйте ngrok в production.

## Проверка подключения

После установки APK на устройство:

1. Откройте приложение
2. Попробуйте войти
3. Если появляется ошибка "Не удалось подключиться к серверу" - проверьте:
   - ✅ Сервер запущен
   - ✅ IP адрес правильный
   - ✅ Устройство и компьютер в одной сети
   - ✅ Брандмауэр не блокирует соединения
   - ✅ Порт 5000 доступен

## Устранение проблем

### Ошибка: "Не удалось подключиться к серверу"

**Решение:**
1. Проверьте, что сервер запущен на компьютере
2. Проверьте IP адрес - он может измениться при переподключении к Wi-Fi
3. Проверьте, что устройство и компьютер в одной сети
4. Попробуйте ping с устройства к компьютеру (если возможно)

### Приложение застревает на заставке

**Решение:**
1. Проверьте логи в Android Studio (если возможно)
2. Убедитесь, что URL правильный и доступен
3. Проверьте, что сервер отвечает на запросы
4. Попробуйте переустановить приложение

### Изменение IP адреса

Если IP адрес компьютера изменился (например, при переподключении к Wi-Fi):
1. Узнайте новый IP (см. Шаг 1)
2. Обновите URL в `ApiService.cs`
3. Пересоберите APK

---

## Рекомендации для production

Для production окружения рекомендуется:
1. Использовать статический IP адрес сервера
2. Настроить доменное имя (например, `api.yourcompany.com`)
3. Использовать HTTPS вместо HTTP
4. Настроить SSL сертификат
5. Использовать переменные окружения для URL вместо hardcode
