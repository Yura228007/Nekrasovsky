# Исправления ошибок компиляции

## ✅ Исправлено

### 1. Ошибки namespace в моделях
- Исправлен неправильный namespace `PasswordManagerV1` в файлах:
  - `Models/FillingWarehouse.cs`
  - `Models/Recipe.cs`

### 2. Настройка целевых платформ для Windows
- Изменен файл `NekrasovskyAPP.csproj` для использования только Windows платформы при разработке на Windows
- Это устраняет ошибки компиляции для Android/iOS платформ, которые не нужны для разработки на Windows

## 📝 Результат

Теперь проект должен компилироваться без ошибок для Windows платформы. Ошибки, связанные с Android/iOS, больше не должны появляться при разработке на Windows.

## 🚀 Запуск

После этих исправлений приложение можно запустить командой:

```powershell
cd NekrasovskyAPP\NekrasovskyAPP
dotnet restore
dotnet build -f net8.0-windows10.0.19041.0
dotnet run -f net8.0-windows10.0.19041.0
```

Или просто через Visual Studio, выбрав платформу Windows.

## ⚠️ Примечание

Если вам понадобится поддержка Android/iOS платформ в будущем:
1. Установите необходимые рабочие нагрузки MAUI
2. Раскомментируйте строки с Android/iOS в файле `.csproj`
3. Убедитесь, что у вас установлен правильный .NET SDK (8.0 для MAUI)
