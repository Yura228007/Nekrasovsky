# Альтернативная библиотека для сканирования штрих-кодов

## 🔍 Проблема

Пакет `ZXing.Net.Maui.Controls` версии 0.5.1 требует .NET 9.0, а проект использует .NET 8.0.

## ✅ Решение: BarcodeScanning.Native.Maui

### Преимущества

1. ✅ **Совместимость с .NET 8.0** - версия 1.7.8 поддерживает `net8.0-android`, `net8.0-ios`, `net8.0-windows`
2. ✅ **Native API** - использует Google ML Kit на Android и Apple Vision на iOS, что обеспечивает:
   - Высокую скорость распознавания
   - Отличное качество распознавания
   - Меньшее потребление ресурсов
3. ✅ **Множество форматов** - поддерживает QR-коды, Code128, EAN13, UPC и другие
4. ✅ **Бесплатная и открытая** - MIT лицензия
5. ✅ **Активная поддержка** - регулярно обновляется

### Минусы

⚠️ **Windows** - поддержка Windows пока ограничена (можно использовать генерацию, но сканирование с камеры может быть недоступно)

## 📦 Установка

```xml
<PackageReference Include="BarcodeScanning.Native.Maui" Version="1.7.8" />
```

## 🔧 Интеграция

### Шаг 1: Удалить старый пакет ZXing

Удалить из `.csproj`:
```xml
<PackageReference Include="ZXing.Net.Maui.Controls" Version="0.4.9" />
```

### Шаг 2: Установить BarcodeScanning.Native.Maui

Добавить в `.csproj`:
```xml
<PackageReference Include="BarcodeScanning.Native.Maui" Version="1.7.8" />
```

### ✅ Шаг 3: Обновление MauiProgram.cs выполнено

**Было:**
```csharp
.UseBarcodeReader() // Initialize ZXing.Net.Maui
```

**Стало:**
```csharp
.UseBarcodeScanning() // Initialize BarcodeScanning.Native.Maui
```

✅ **Изменения внесены в проект!**

### ✅ Шаг 4: Обновление использования в коде выполнено

#### Для ZXing (старое):
```xml
<barcode:ZXingBarcodeReaderView
    x:Name="BarcodeReader"
    BarcodeOptions="{Binding BarcodeOptions}"
    BarcodesDetected="OnBarcodesDetected" />
```

#### Для BarcodeScanning.Native.Maui (новое):
```xml
<barcode:CameraView
    x:Name="BarcodeCamera"
    CameraEnabled="{Binding IsCameraEnabled}"
    OnDetectionFinishedCommand="{Binding DetectionFinishedCommand}" />
```

### ✅ Шаг 5: Обновление обработки событий выполнено

**Создана страница `BarcodeScannerPage.xaml` и `BarcodeScannerPage.xaml.cs`:**

```csharp
public ICommand DetectionFinishedCommand { get; }

private void OnDetectionFinished(IReadOnlySet<BarcodeResult>? results)
{
    if (results != null && results.Count > 0)
    {
        var barcode = results.First();
        string barcodeValue = barcode.Text;
        // Использовать значение штрих-кода
        BarcodeScanned?.Invoke(this, barcodeValue);
    }
}
```

### ✅ Шаг 6: Интеграция в ProductsPage выполнена

Добавлена кнопка "Сканировать" в тулбар страницы продуктов:
- При нажатии открывается модальная страница сканера
- После сканирования результат автоматически вставляется в поле поиска
- Выполняется поиск продукта по штрих-коду

## 🚀 Быстрый старт

После установки пакета можно сразу начать использовать:

1. Добавить `BarcodeCameraView` в XAML
2. Подписаться на событие `BarcodesDetected`
3. Обработать результат сканирования

## 💡 Пример использования

```xml
<ContentPage xmlns="http://schemas.microsoft.com/dotnet/2021/maui"
             xmlns:x="http://schemas.microsoft.com/winfx/2009/xaml"
             xmlns:barcode="clr-namespace:CommunityToolkit.Maui.Views;assembly=CommunityToolkit.Maui"
             x:Class="NekrasovskyAPP.Pages.BarcodeScannerPage">
    <Grid>
        <barcode:BarcodeCameraView
            x:Name="BarcodeCamera"
            BarcodesDetected="OnBarcodesDetected"
            TorchOn="{Binding IsTorchOn}"
            VibrateOnDetected="True" />
    </Grid>
</ContentPage>
```

```csharp
private void OnBarcodesDetected(object sender, BarcodeDetectionEventArgs e)
{
    if (e.Results?.Any() == true)
    {
        var barcode = e.Results.First();
        // Обработать результат
        ProcessBarcode(barcode.Value);
    }
}
```
