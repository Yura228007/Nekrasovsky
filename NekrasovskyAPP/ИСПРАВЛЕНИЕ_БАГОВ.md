# Исправление багов приложения

## 🐛 Баг 1: Нельзя войти после выхода

### Проблема
После входа в аккаунт и выхода невозможно снова войти - нужно перезапускать приложение.

### Причина
Событие `LoginSuccess` отписывалось при скрытии страницы, но не подписывалось снова при возврате.

### ✅ Исправлено

1. **Подписка на событие перенесена в `OnAppearing()`** вместо конструктора
   - Теперь событие подписывается каждый раз при появлении страницы
   - Гарантирует работу даже после выхода и повторного входа

2. **Добавлен метод `ClearState()` в `LoginViewModel`**
   - Очищает состояние формы при возврате на страницу входа
   - Сбрасывает ошибки и поля ввода

3. **Улучшена навигация при выходе**
   - Используется `///LoginPage` для полного сброса стека навигации
   - Гарантирует, что LoginPage создается заново

## 🐛 Баг 2: APK застревает на заставке

### Проблема
При установке APK на реальное Android устройство приложение застревает на заставке и не подключается к серверу.

### Причина
URL сервера настроен на `http://10.0.2.2:5000/` - это работает только для эмулятора. Для реального устройства нужен IP адрес компьютера в локальной сети.

### ✅ Решение

#### Быстрое исправление:

1. **Узнайте IP адрес вашего компьютера:**
   ```bash
   # macOS/Linux
   ifconfig | grep "inet " | grep -v 127.0.0.1
   
   # Windows
   ipconfig
   ```

2. **Обновите URL в `ApiService.cs`:**
   
   Откройте: `NekrasovskyAPP/NekrasovskyAPP/Services/ApiService.cs`
   
   Найдите метод `GetBaseUrl()` и замените:
   ```csharp
   #if ANDROID
       // Замените XXX на ваш IP адрес
       string androidUrl = "http://192.168.1.XXX:5000/";
       return androidUrl;
   #endif
   ```

3. **Убедитесь, что:**
   - ✅ Сервер запущен на компьютере
   - ✅ Компьютер и устройство в одной Wi-Fi сети
   - ✅ Брандмауэр не блокирует порт 5000
   - ✅ Сервер доступен по IP (проверьте в браузере на устройстве: `http://ВАШ_IP:5000/swagger`)

4. **Пересоберите APK:**
   ```bash
   cd NekrasovskyAPP/NekrasovskyAPP
   dotnet publish -f net8.0-android -c Release
   ```

#### Подробная инструкция:
См. [НАСТРОЙКА_ANDROID_APK.md](./НАСТРОЙКА_ANDROID_APK.md)

## 📝 Дополнительные рекомендации

### Для разработки:
- Используйте эмулятор для быстрого тестирования (`http://10.0.2.2:5000/`)
- Для реального устройства настройте IP адрес

### Для production:
- Используйте доменное имя вместо IP
- Настройте HTTPS и SSL сертификат
- Используйте переменные окружения для URL
- Настройте статический IP адрес сервера
