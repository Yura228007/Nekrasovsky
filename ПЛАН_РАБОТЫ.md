  - Понять, как сейчас работает назначение ответственности
- [ ] Создать новую модель или расширить существующую для хранения количества
  - Вариант 1: Добавить поле `Quantity` в таблицу `Responsibility`
  - Вариант 2: Создать отдельную таблицу `ResponsibilityQuantity` для связи ответственности и количества
- [ ] Обновить сервис `ResponsibilityService`
  - Изменить методы `AssignMaterialAsync` и `AssignProductAsync` для принятия количества
  - Обновить методы получения ответственности для включения информации о количестве
  - Обновить метод `GetResponsibilityStockAsync` для корректного отображения количества
- [ ] Обновить контроллер `ResponsibilitiesController`
  - Изменить запросы назначения для принятия количества
  - Обновить DTO для передачи количества
- [ ] Создать миграцию базы данных
  - Добавить поле количества или новую таблицу
  - Обеспечить обратную совместимость с существующими данными
- [ ] Обновить UI для отображения и управления количеством
  - Показать количество в списках ответственных лиц
  - Добавить возможность указать количество при назначении ответственности
