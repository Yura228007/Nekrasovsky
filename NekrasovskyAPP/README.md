# Nekrasovsky MAUI App

Кроссплатформенное приложение для системы управления складом Nekrasovsky, разработанное на .NET MAUI.

## 🚀 Быстрый старт

### Предварительные требования

- .NET 8.0 SDK
- Visual Studio 2022 с поддержкой MAUI или Visual Studio Code
- Запущенный сервер (см. основной README.md)

### Настройка подключения к серверу

Приложение автоматически определяет платформу и использует соответствующий базовый URL:

- **Windows/Desktop/iOS/Mac**: `http://localhost:5000/`
- **Android эмулятор**: `http://10.0.2.2:5000/`
- **Android реальное устройство**: необходимо изменить URL в `Services/ApiService.cs` на IP вашего компьютера (например, `http://192.168.1.100:5000/`)

### Запуск приложения

```bash
cd NekrasovskyAPP/NekrasovskyAPP
dotnet restore
dotnet build
dotnet run
```

## 🏗️ Архитектура

Приложение использует:

- **MVVM паттерн** - разделение логики и представления
- **Dependency Injection** - через встроенный DI контейнер MAUI
- **RESTful API** - взаимодействие с сервером через HTTP
- **Modern UI** - Material Design элементы и современный UX

## 🔧 Настройка для Android

Для подключения к серверу с реального Android устройства:

1. Узнайте IP адрес вашего компьютера в локальной сети
2. Откройте файл `Services/ApiService.cs`
3. Найдите метод `GetBaseUrl()` и измените URL для Android:

```csharp
#if ANDROID
    return "http://ВАШ_IP_АДРЕС:5000/"; // Например: "http://192.168.1.100:5000/"
#else
    return "http://localhost:5000/";
#endif
```

4. Убедитесь, что сервер доступен по этому адресу
5. Пересоберите приложение

## 📝 Примечания

- Приложение автоматически обрабатывает ошибки сети
- Все запросы имеют таймаут 30 секунд
- Данные кэшируются в памяти для быстрого доступа
- Поддерживается pull-to-refresh на всех страницах со списками

## 🐛 Решение проблем

### Приложение не подключается к серверу

1. Убедитесь, что сервер запущен и доступен
2. Проверьте правильность URL в `ApiService.cs`
3. Для Android: убедитесь, что устройство и компьютер в одной сети
4. Проверьте настройки файрвола

### Ошибки компиляции

1. Убедитесь, что установлен .NET 8.0 SDK
2. Выполните `dotnet restore`
3. Очистите решение и пересоберите
