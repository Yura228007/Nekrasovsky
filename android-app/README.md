# Nekrasovsky Android App

Нативное Android приложение для системы управления складом Nekrasovsky.

## Технологии

- **Kotlin** - основной язык программирования
- **Jetpack Compose** - современный UI фреймворк
- **Material Design 3** - дизайн система
- **Retrofit** - HTTP клиент для работы с API
- **Hilt** - dependency injection
- **Coroutines** - асинхронное программирование
- **MVVM** - архитектурный паттерн

## Структура проекта

```
app/src/main/java/com/nekrasovsky/android/
├── data/
│   ├── api/              # Retrofit API интерфейсы
│   ├── model/            # Модели данных
│   └── repository/       # Репозитории
├── ui/
│   ├── navigation/        # Навигация
│   ├── screens/          # Экраны приложения
│   └── theme/            # Тема и стили
└── MainActivity.kt       # Главная активность
```

## Настройка

### 1. Настройка базового URL API

Откройте файл `app/src/main/java/com/nekrasovsky/android/data/api/RetrofitModule.kt` и измените `BASE_URL`:

- Для эмулятора Android: `http://10.0.2.2:5000/`
- Для реального устройства: `http://<IP_ВАШЕГО_КОМПЬЮТЕРА>:5000/`

Например: `http://192.168.1.100:5000/`

### 2. Сборка проекта

1. Откройте проект в Android Studio
2. Дождитесь синхронизации Gradle
3. Подключите Android устройство или запустите эмулятор
4. Нажмите Run (Shift+F10)

## Функциональность

### Экраны приложения

1. **Экран входа (Login)**
   - Авторизация пользователя
   - Валидация полей

2. **Главный экран (Dashboard)**
   - Навигация по разделам приложения
   - Карточки быстрого доступа

3. **Продукты (Products)**
   - Просмотр списка продуктов
   - Поиск продуктов
   - Добавление/редактирование продуктов

4. **Материалы (Materials)**
   - Просмотр списка материалов
   - Поиск материалов
   - Управление материалами

5. **Склады (Warehouses)**
   - Просмотр списка складов
   - Информация о складах
   - Управление складами

6. **Отчеты о работе (Work Reports)**
   - Просмотр отчетов
   - Начало/окончание работы
   - История работы

## API Endpoints

Приложение использует следующие API endpoints:

- `GET /api/users` - список пользователей
- `GET /api/products` - список продуктов
- `GET /api/materials` - список материалов
- `GET /api/warehouses` - список складов
- `GET /api/work-reports` - отчеты о работе
- `POST /api/work-reports/start` - начать работу
- `POST /api/work-reports/{id}/finish` - завершить работу

И другие endpoints согласно API сервера.
