# Реализация ролей и прав

## Выполнено

### ✅ 1. Модель Role
- Создана модель `Role` с полями:
  - `Id` - первичный ключ
  - `Name` - название роли
  - `Code` - код роли (для программного использования)
  - `Description` - описание роли
  - `Rank` - ранг роли (для определения иерархии)

### ✅ 2. Связь User-Role
- Добавлено поле `RoleId` в модель `User`
- Добавлена навигационное свойство `Role` в `User`
- Настроена связь в `AppDbContext` с `OnDelete(DeleteBehavior.SetNull)`

### ✅ 3. Модель RolePermission
- Создана модель `RolePermission` для связи ролей и прав (many-to-many)
- Настроены связи в `AppDbContext`

### ✅ 4. Роли из ТЗ
Добавлены следующие роли (на основе ТЗ, раздел 5.3):
1. Владелец (Owner, Rank: 0)
2. Администратор (Admin, Rank: 1)
3. Старший экструзионщик (SeniorExtruder, Rank: 2)
4. Экструзионщик (Extruder, Rank: 3)
5. Старший кладовщик (SeniorStorekeeper, Rank: 2)
6. Кладовщик (Storekeeper, Rank: 3)
7. Покрасочник (Painter, Rank: 3)
8. Старшая упаковщица (SeniorPacker, Rank: 2)
9. Кладовщик готовой продукции (FinishedProductStorekeeper, Rank: 3)
10. ТПА (TPA, Rank: 3)
11. Утиль (Waste, Rank: 4)

### ✅ 5. Права из ТЗ
Добавлены следующие права (на основе ТЗ, раздел 5.4):
1. AddUsersAllRanks - Добавление пользователей всех рангов
2. AddUsersLowerRanks - Добавление пользователей ниже рангом
3. Reception - Приемка (приемка сырья станков и т.д. на производство)
4. AssignBarcode - Назначение штрихкода (позиции, таре и т.д.)
5. SendToWaste - Отправка на Утиль
6. SendToSDH - Отправка на СДХ
7. SendToSale - Отправка на реализацию
8. WriteOff - Списание (выбросить)
9. MoveFromMainToWorkshop - Перенос ТМЦ из Основного склада в цеха
10. MoveFromWorkshopToMain - Перенос ТМЦ из Цеха на Основной склад
11. ShiftTransfer - Передача смены
12. ManageRecipes - Создание и добавление рецептур, единиц хранения
13. Inventory - Инвентаризация

### ✅ 6. Real-time уведомления для Alarm
- Добавлена отправка уведомлений через SignalR Hub при создании `AlarmEvent`
- Уведомления отправляются всем подключенным пользователям
- Добавлены методы подписки/отписки на уведомления о тревогах в `NotificationHub`

## Требуется уточнить

### ❓ 1. Права для ролей
**Файл:** `Список прав (запрос програмистов).xlsx`

Нужно определить, какие из 13 прав должны быть назначены каждой из 11 ролей.

После получения этой информации нужно:
1. Обновить метод `SeedRolesAndPermissions.SeedData()` в файле `server/server/Migrations/SeedRolesAndPermissions.cs`
2. Добавить создание записей в таблицу `RolePermission`

Пример структуры (нужно уточнить):
```csharp
// Владелец - все права
var ownerRole = context.Roles.First(r => r.Code == "Owner");
var allPermissions = context.Permissions.ToList();
foreach (var permission in allPermissions)
{
    context.RolePermissions.Add(new RolePermission 
    { 
        RoleId = ownerRole.Id, 
        PermissionId = permission.Id 
    });
}

// Администратор - определенные права
// ... и так далее для каждой роли
```

### ❓ 2. Список цехов
**Файл:** `Список цехов и их взаимодействие (3).xlsx`

Нужно определить:
- Названия цехов
- Их взаимодействие (какие цеха могут обмениваться товаром)
- Тип цеха (склад, производственный цех и т.д.)

После получения этой информации нужно:
1. Обновить метод `SeedWorkshops.SeedData()` в файле `server/server/Migrations/SeedWorkshops.cs`
2. Добавить цеха в таблицу `Warehouse` с `Type = "Цех"`
3. Настроить `AccessibleMovement` для разрешенных перемещений между цехами

### ❓ 3. Миграция базы данных
После получения информации о правах для ролей и списка цехов нужно:
1. Создать миграцию для таблиц `Role` и `RolePermission`
2. Добавить вызовы `SeedRolesAndPermissions.SeedData()` и `SeedWorkshops.SeedData()` в метод `Up()` миграции
3. Применить миграцию к базе данных

## Следующие шаги

1. **Получить информацию из файлов:**
   - Скопировать содержимое файла "Список прав" в текстовый формат
   - Скопировать содержимое файла "Список цехов" в текстовый формат

2. **Обновить скрипты заполнения:**
   - Заполнить права для каждой роли в `SeedRolesAndPermissions.cs`
   - Заполнить список цехов в `SeedWorkshops.cs`

3. **Создать и применить миграцию:**
   ```bash
   dotnet ef migrations add AddRolesAndWorkshops --context AppDbContext
   dotnet ef database update --context AppDbContext
   ```

4. **Обновить логику проверки прав:**
   - Обновить `RequirePermissionAttribute` для проверки прав через роль
   - Добавить методы в сервисы для работы с ролями
