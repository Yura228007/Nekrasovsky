# 📱 Инструкция по запуску MAUI приложения Nekrasovsky

## 🔧 Предварительные требования

1. **.NET 8.0 SDK** - должен быть установлен
2. **Visual Studio 2022** с установленной рабочей нагрузкой ".NET Multi-platform App UI development" 
   ИЛИ
   **Visual Studio Code** с расширениями для .NET и MAUI
3. **Запущенный сервер** - API сервер должен быть запущен и доступен

## 🚀 Пошаговая инструкция

### Шаг 1: Запуск сервера (обязательно!)

Перед запуском приложения необходимо запустить сервер:

```bash
# Перейти в папку сервера
cd server/server

# Восстановить зависимости (если нужно)
dotnet restore

# Применить миграции базы данных
dotnet ef database update

# Запустить сервер
dotnet run
```

Сервер будет доступен по адресу:
- HTTP: `http://localhost:5000`
- HTTPS: `https://localhost:5001`
- Swagger UI: `http://localhost:5000/swagger`

**Важно:** Сервер должен быть запущен перед запуском приложения!

---

### Шаг 2: Настройка подключения к серверу

Приложение автоматически определяет платформу и использует соответствующий базовый URL:

#### Для Windows (Desktop)
- URL уже настроен: `http://localhost:5000/`
- Ничего менять не нужно

#### Для Android эмулятора
- Откройте файл: `NekrasovskyAPP/NekrasovskyAPP/Services/ApiService.cs`
- Найдите метод `GetBaseUrl()` 
- Убедитесь, что для Android указано: `http://10.0.2.2:5000/`

#### Для Android реального устройства
1. Узнайте IP адрес вашего компьютера в локальной сети
2. Откройте файл: `NekrasovskyAPP/NekrasovskyAPP/Services/ApiService.cs`
3. Найдите метод `GetBaseUrl()`
4. Измените URL для Android на IP вашего компьютера:
   ```csharp
   #if ANDROID
       return "http://192.168.1.100:5000/"; // Замените на ваш IP
   #endif
   ```

---

### Шаг 3: Запуск приложения

#### Способ 1: Через Visual Studio 2022 (Рекомендуется)

1. Откройте решение `NekrasovskyAPP.sln` в Visual Studio 2022
2. Выберите целевую платформу в выпадающем списке (Windows, Android, iOS)
3. Нажмите **F5** или кнопку **Запустить**

#### Способ 2: Через командную строку (Windows)

```powershell
# Перейти в папку проекта
cd NekrasovskyAPP\NekrasovskyAPP

# Восстановить зависимости
dotnet restore

# Собрать проект
dotnet build -f net8.0-windows10.0.19041.0

# Запустить приложение
dotnet run -f net8.0-windows10.0.19041.0
```

#### Способ 3: Через командную строку (Android)

```powershell
# Перейти в папку проекта
cd NekrasovskyAPP\NekrasovskyAPP

# Восстановить зависимости
dotnet restore

# Запустить на подключенном Android устройстве или эмуляторе
dotnet build -t:Run -f net8.0-android
```

## 📝 Первый запуск

1. При первом запуске откроется **страница входа (LoginPage)**
2. Введите логин и пароль пользователя из базы данных
3. После успешного входа:
   - **Обычный пользователь** → перенаправляется на **HomePage**
   - **Администратор** (логин "admin" или с разрешением "Admin") → перенаправляется на **AdminPage**

---

## 🔍 Проверка работы

После запуска приложения:

1. **Проверьте подключение к серверу:**
   - Если видите ошибки сети, проверьте, что сервер запущен
   - Убедитесь, что URL в `ApiService.cs` правильный

2. **Проверьте вход:**
   - Убедитесь, что пользователь существует в базе данных
   - Для тестирования можно создать пользователя через API или базу данных

3. **Проверьте навигацию:**
   - После входа должны быть доступны все разделы
   - Кнопка "Выход" должна возвращать на страницу входа

## ⚠️ Решение проблем

### Ошибка: "Не удается подключиться к серверу"

**Решение:**
1. Проверьте, что сервер запущен на порту 5000
2. Проверьте настройки URL в `Services/ApiService.cs`
3. Для Android устройства убедитесь, что устройство и компьютер в одной сети

### Ошибка: "Сборка не удалась"

**Решение:**
1. Убедитесь, что установлен .NET 8.0 SDK
2. Проверьте, что установлена рабочая нагрузка MAUI в Visual Studio
3. Выполните `dotnet restore` и `dotnet clean`, затем попробуйте снова

### Ошибка: "Пользователь не найден" при входе

**Решение:**
1. Убедитесь, что пользователь существует в базе данных
2. Проверьте правильность логина и пароля
3. Убедитесь, что пароль не зашифрован дважды в базе данных

### Приложение не запускается на Windows

**Решение:**
1. Убедитесь, что выбрана платформа `net8.0-windows10.0.19041.0`
2. Проверьте, что установлены необходимые компоненты Windows SDK
3. Попробуйте запустить от имени администратора
